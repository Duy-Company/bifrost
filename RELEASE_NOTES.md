Bifrost's first Windows receiver release.

- Minimal English welcome screen with white and ice-blue branding.
- Background system tray receiver; closing the welcome window keeps it running.
- Bundled AirPlay engine for Mac, iPhone and iPad, with a separate native-framed stream window and fullscreen control.
- Windows Wireless Display integration for compatible Miracast / Smart View devices.
- Automatic GitHub update checks, background downloads and restart-to-update from the tray.

Windows x64. Miracast requires Windows Wireless Display and compatible drivers. Google Cast/Chromecast is not supported. Physical AirPlay/Miracast sessions have not been verified. The installer is unsigned.
